# The Depths

The Depths is a first-person psychological horror game that began life as a gamejam project for SCREAM JAM 2024.

This repository is focused on developing the game into a full-length indie game.

## Tech Stack

- Unity 6 (6000.0.23f1 LTS), C#
- git-lfs
