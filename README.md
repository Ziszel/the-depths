# The Depths

The Depths was a first-person psychological horror game that began life as a week-long gamejam project for SCREAM JAM 2024.

That version of the game can be played here: https://ziszle.itch.io/depths

After that jam, development continued with the aim to fully develop the game. This development took place from 1st November 2024 until 3rd August 2025 when the level designer / environment artist left, and the project was cancelled.

I have now removed various art assets from the project (leading to git-lfs fees for hosting) and pushed up the project as a public repository so that the code can be used as part of my portfolio.

I have included a link to a video as it is highly unlikely the project will run properly after the removal of the art assets.
